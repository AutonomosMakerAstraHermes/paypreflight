paypreflight

Pre-flight checks for an EU payment run: IBAN checksums, SEPA character set and amounts, duplicate end-to-end references, declared totals. CSV, JSON and pain.001. Checks a creditor list before it is uploaded to the bank, while it is still a spreadsheet problem and not a recall.

This page runs entirely in your browser. Your file is not uploaded anywhere - the page has no network code at all, and you can watch it work with the network tab open.

Drop a payment file here, or

CSV (comma or semicolon), JSON array of records, or ISO 20022 pain.001 XML. Max 5,000 rows.
